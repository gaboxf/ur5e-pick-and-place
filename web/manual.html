Manual operativo

Cómo instalar, calibrar, operar y diagnosticar la celda. Está pensado para un operario que nunca vio el proyecto: si seguís los pasos en orden, la celda funciona.

Seguridad: parada de emergencia

Cambio de arquitectura — leé esto primero

El Arduino del gripper no tiene botón físico de parada de emergencia: fue desacoplado y descontinuado. La única parada de emergencia válida y primaria es el pulsador de hongo (E-Stop) del Teach Pendant del UR5, que corta la energía de las articulaciones por circuito cableado, sin depender de Python ni de la PC.

La interfaz web sirve para paradas programadas únicamente.

Procedimiento ante una anomalía

  1. 01

    Presionar el E-Stop del Teach Pendant

    Acciona con la palma el pulsador de hongo. Esto corta de inmediato la energía en las articulaciones del brazo.

  2. 02

    Desplazar el robot con el joystick

    Con el sistema en modo seguro, guiá la herramienta a una zona despejada, lejos de interferencias mecánicas con la celda.

  3. 03

    Confirmar el estado por software

    Verificá la telemetría en el dashboard: desconexión limpia del socket RTDE y liberación del hilo de captura. La parada por software es solo para cortes programados, con reinicio explícito del ciclo.

  4. 04

    Nunca buscar un botón en el Arduino

    No existe. El Arduino solo conmuta los pulsos de los servos TPU; no contiene circuito de corte de alimentación de fuerza del brazo.

Puesta en marcha

Windows o Linux, con URsim como emulador o el UR5 real en la red. Python 3.10–3.12 de 64 bits con “Add Python to PATH”.

1 · Entorno virtual

Aísla los paquetes para evitar conflictos de bibliotecas binarias.

py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt

2 · Arduino y puerto serie

Conectá el Arduino por USB. Si no aparece en el Administrador de dispositivos, instalá el driver CH340. El firmware del gripper espera el puerto configurado en gripper_port a 115200 baudios.

# Verificar puertos disponibles
[System.IO.Ports.SerialPort]::GetPortNames()
# → "COM3"

3 · Robot: URsim o UR5 real

El emulador URsim escucha en loopback; el robot real queda en la red. Toda trayectoria nueva se valida primero en el emulador.

# Probar el socket URScript
Test-NetConnection -Port 30004 -ComputerName 127.0.0.1
# TcpTestSucceeded: True

4 · Arrancar la celda

Con el venv activado, lanzá el dashboard y abrí el navegador.

.\.venv\Scripts\Activate.ps1
python core/dashboard_web.py
# → http://localhost:5000

La calibración (ROI, HSV, homografía) se hace desde el propio dashboard y se guarda en vision/config.json, donde persiste entre sesiones.
